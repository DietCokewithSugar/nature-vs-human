# 人类账单支付

自然界联合起来，从人类手里把地收回来。挂机放置 + Plague Inc. 式的研究赛跑 + 红色警戒式的盖建筑、出兵、抢地盘。

- 开局人类占了大半张地图，你（自然）只有几小块分散的飞地。
- 你不再一只一只买动物，而是用 **自然之元** 盖窝：每座窝隔一段时间生一只（或几种）动物，最多升级 3 次，级别越高生得越快越多。
- 动物会自己去咬人、拆房子、把人类的地啃回来；人类也会自己盖房、出兵、开荒，把地抢回去。地块属于谁，取决于双方把它“侵占”到了多少。
- 所有单位都有 **血条**（红）和 **寿命条**（白）：打仗掉血，脱战、觅食、休息会回血；寿命到了就老死，只有技能树能延长。
- 有 **昼夜**（屏幕最上方的日月条）。动物和人都要按自己的作息去觅食和休息，每个个体的时间按正态分布各不相同。
- 人类在研究：每研究满一段就进入下一个时代，地图向外扩大一圈，人类建筑整体升级。现代时期还占不到 65% 的地，研究一满你就输了。

规则详见 [docs/design.md](docs/design.md)，数值验证见 [docs/balance.md](docs/balance.md)。没有离线收益：页面开着就算在线，关掉不累计。

## 一局怎么玩

| 项目 | 规则 |
|---|---|
| 胜利 | 现代时期，自然占当前地图可占地块的 65%；或者把人类所有建筑拆光 |
| 失败 | 人类研究满（四段，对应四个时代）；或者自然一座建筑都不剩 |
| 自然之元 | 资源点会冒出发光的「元」泡泡，**点它收集**（点击不再能破坏人类建筑）；每块自然领地每秒也有一点被动收入；技能树里的授粉者（蜜蜂、蝴蝶白天，蝙蝠夜里）会自动去收泡泡。人类也靠自然之元盖房、扩张 |
| 盖建筑 | 在「建筑」页点一座，地图上能盖的格子会亮起来：**绿色** 自己的领地（正常速度）、**金色** 中立地（只有 1/5 的速度）、敌方领地不能盖（技能「地下通道」能让蚁穴盖在人类领地）。也可以点「自动选址」 |
| 建筑上限 | 3 + 每 7 块自然领地 1 座。占的地越多，能盖的越多 |
| 升级 | 每座最多升 3 次（1 → 4 级）：生得更快、在外的上限更高、3 级起一次生两只、外壳更厚。**建筑不能修复**，升级只加新的那部分血量 |
| 领地 | 每块地有一个 −100（人类）到 +100（自然）的控制值，越过 ±50 换主人。动物站在人类地块上会把它啃回来，人类的开荒单位也在反方向推；有建筑的地块要先把建筑拆了才能翻。没人动的地块会慢慢回到原主人手里 |
| 集结旗 | 点技能栏的旗子再点地图，动物会优先往那边打 |
| 单位 | 自动行动。血条红、寿命条白；脱战 6 秒后回血，休息、觅食时回得更快 |
| 昼夜与作息 | 一天 4 分钟，开局早上 6 点。每个物种有觅食和休息的习惯时段，每个个体出生时按正态分布抽自己的时间（狼大多夜里出来，但也有白天觅食的；原始人全天都有人打猎；现代上班族朝九晚六，夜里很少出门）。觅食和休息不会同时进行，头上会显示状态图标 |
| 以战代食 | 狼、剑齿虎、老虎、鳄鱼、鲨鱼、蚊子咬人类，猎人、猎枪手、狗打动物，蚂蚁、白蚁啃木头房子，蝗虫、老鼠、野猪啃农田：这些都算觅食，打的同时回血 |
| 时代 | 冰河 → 古代 → 工业 → 现代，由人类研究推动。每进一个时代地图扩大一圈（20×20 → 32×32 格），新的一圈带着自己的密林、资源点和双方的前哨；人类建筑整体换成下一个时代的样子 |
| 人类的反击 | 研究每段过半时，针对你攻击力最高的兵种推出反制（攻击下降）；猎人和研究员会抓你的狼、野猫、野猪，驯化满 100% 时整批跳反成狗、家猫、家猪；你占的地越多，人类研究越快、收入越多；现代之前你就超过 65%，人类会紧急研发（研究 ×4） |
| 灾难 | 古代起每 5 到 8 分钟：海啸（西南海湾）、龙卷风（东北平原）、火山爆发（火山）。灾区里谁都掉血，只有借势的兵种不受伤、攻击翻倍 |
| 局外成长 | 每局结算基因点，解锁开局路线、技能分叉 B 和永久天性。难度：普通、困难、残酷 |

- 人类占中间和东边一大片；自然只有西北火山旁、西南河口、城里的公园、东北林地、东南小树林几块飞地。
- **中立领地** 是非常茂密的森林和荒沙丘：双方都能占，但都慢（人类伐木开荒，动物在里面觅食、筑巢慢慢同化）。在中立地上盖建筑只有 1/5 的速度，盖好以后这块地就归你。
- **火山和水** 谁也占不了。
- 双方开局附近都有森林、水、沙地和火山四种资源：自然的飞地挨着火山、河口、沙滩和林子；人类的城挨着河、湖、白沙滩、火山东麓和密林。很多建筑要挨着某种资源才能盖（见下表的「选址」）。
- 资源点是地图上固定的几处（林边、河岸、沙滩、火山口），谁占着那块地谁就从那里收自然之元：自然方冒泡泡，人类方直接入账。

## 两方的领地

人类的地被推平、铺成那个时代的样子；自然的地起伏、杂乱、开满野花。被对方侵占到一半时，地面会混着两边的样子（城里长出杂草，野地被踩成泥地）。

| 时代 | 人类领地 | 自然领地 |
|---|---|---|
| 冰河 | 平整踩实的土地 | 开满野花、参差不齐的草地；冰川；杂乱、长着芦苇和淤泥的溪流 |
| 古代 | 稻田（一行稻一行水）、石板小路、规整的溪流（石砌河岸） | 同上，草地里有灌木和树 |
| 工业 | 砖地和瓷砖地、铺石路、街灯 | 杂草丛生的沙地、各种颜色石子的海滩 |
| 现代 | 柏油路网、修剪整齐的草坪、花坛、纯白的海滩、行道树 | 自然收复的地块上会长出藤蔓和野花 |
| 任何时代 | — | 中立：非常茂密的森林、荒沙丘 |

- **大石坝**：盖在河上（必须挨着人类自己的地），挡住鳄鱼、章鱼、鲨鱼等水生动物顺河而上；人类自己的渔船照样能过。把坝拆了水路才通。
- **电灯**：人类有电以后（工业时代）才会盖。夜里把昆虫和鸟迷得绕着灯打转（头上冒「💫」），还会减速；蝙蝠靠回声定位，不受影响。
- **捕虫灯**：白天也通电，昆虫靠近就持续掉血，夜里吸得更远，常常和电灯搭配。
- **机场**：放出飞机，飞机在城市上空巡航，给人类挣自然之元。只有鸟能够得着飞机：**鸟撞上飞机，飞机直接坠毁，鸟也一起死**。

## 单位

血量是满级技能之前的基础值；人类的血量还会乘以难度倍率。攻击是每秒伤害。寿命单位是游戏天（一天 4 分钟）。觅食、休息一栏是这个物种的平均开始时间和持续时长，括号里是个体之间的标准差（小时）。

### 克制与特殊规则

每个单位都有标签（昆虫、鸟、野兽、水生动物、猎人、人类、车辆、船、飞机、家畜……），每座建筑都有材质（天然、木制、石造、砖瓦、钢筋）和特征（玻璃大楼、农田粮仓、水坝）。攻击时看对方最具体的那个标签：比如猎人同时是「猎人」和「人类」，狼打他用「对猎人」的倍率。

| 规则 | 例子 |
|---|---|
| 克制倍率 | 蚂蚁对木制建筑 ×3、对人 ×0.35；白蚁对木头 ×4；狼对普通人 ×1.6、对猎人只有 ×0.5；猎人对野兽 ×1.5、对昆虫 ×0.3；蝗虫对农田 ×3；家猫对老鼠 ×2.5；犀牛对车辆 ×2.5；鲨鱼对船 ×2.2；鸽子对石造建筑 ×1.6；大象对玻璃大楼 ×1.5 |
| 反伤 | 鸟啄摩天大楼、研究所、购物中心这类玻璃大楼，每啄一下自己掉 30% 血；出租车撞猛犸、野牛、犀牛、大象，自己也会掉血 |
| 同归于尽 | 鸟撞飞机：飞机坠毁，鸟也死 |
| 打不动 | 蚊子叮不动车辆和飞机；除了鸟，谁也够不着飞机；近战的陆地动物追不到水里的单位 |
| 以战代食 | 见上文：咬到对的目标就算觅食，打的同时回血 |
| 捕获 | 研究员、动物管理员把动物打到 35% 血以下就直接抓走，计入驯化进度 |
| 救治 | 实验室偶尔出环保工作者：人类阵营，但专门给受伤的动物治疗，双方都不会打他 |

## 技能树

用自然之元购买，分六条线：刺客、群体、猎手、重坦、水军、通用。

- 通用：授粉（蜂巢）→ 花海、夜行授粉（蝙蝠洞）、涌泉（泡泡更多更值钱）；隐匿 → 捣毁实验室；自愈、野地筑巢（中立地上建造更快）、蔓生（自然领地自己向中立地蔓延）、狡兔三窟（建筑上限 +3）、长寿、野蛮生长。
- 刺客：成群结队 → 地下通道（蚁穴能盖在人类领地）→ 抗药性 → 携带病毒 / 精神污染（二选一）→ 传播链。
- 群体：繁殖巢（一次多生一只）、鼠疫、多子多福（寿命）、遮天蔽日。
- 猎手：野性难驯 → 解救（主动技能）、狼群战术 → 头狼（寿命）→ 顶级掠食者；趋同进化·虎。
- 重坦：厚皮 → 暴走（主动技能）、重甲 / 践踏（二选一）→ 长寿巨兽；趋同进化·象。
- 水军：潮汐 → 大潮（主动技能）→ 潮汐力 → 风暴潮；深海。

寿命只能靠技能树延长，买下时活着的单位也一起变长寿。

## 本地运行

需要 Node 22.12 或更高版本。

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # 逻辑核心 + 排行榜 SQL 测试
npm run sim          # 三种机器人各打一局，看胜负和用时
npm run report       # 多个种子跑完整局，重新生成 docs/balance.md
npm run models       # 用 Blender 重新生成自制模型（见下面"素材"）
```

没有配置 Supabase 也能玩，排行榜会显示离线。

## 架构

按增量游戏通用分层组织，逻辑核心不依赖引擎和平台：

| 层 | 目录 | 内容 |
|---|---|---|
| 外壳 | `src/shell/` | 启动、20 Hz 循环、自动存档。以后加 Steam（Electron/Tauri）和手机（Capacitor）外壳，只换这一层 |
| 表现层 | `src/scene/`、`src/ui/`、`src/styles/` | three.js 地图和 Preact 界面，只读状态、发指令。`scene/terrain.ts` 按地块画地形和领地，`decor.ts` 按领地摆树和花，`city.ts` 画建筑、单位、泡泡、血条和昼夜，`marks.ts` 是血条、寿命条和头顶图标 |
| 逻辑核心 | `src/core/` | 纯 TypeScript，可以在 Node 里直接跑。`map/` 是固定地图和寻路，`sim/` 是模拟：领地、单位 AI 与战斗、作息、建筑生产、效果建筑、人类 AI、研究、驯化、灾难 |
| 数据 | `src/core/config/`、`src/data/`、`supabase/` | 配置表、本地存档与迁移、排行榜 |

几个约定：

- 所有数值在 `src/core/config/`：`units.ts`（血量、攻击、寿命、作息、克制）、`buildings.ts`（价格、产出、效果）、`balance.ts`（经济、领地、研究）、`skills.ts`。调数值不用改公式。
- 地图在 `src/core/map/grid.ts`：上面那张字符图就是源码，改字符就改地图。
- 模拟用固定步长（0.1 秒）和带种子的随机数，同一个种子打出来的局一模一样，测试和平衡报告都靠这一点。
- 所有界面文案在 `src/ui/copy.ts`，方便统一审稿和以后翻译。
- 所有颜色来自 [Radix Colors](https://www.radix-ui.com/colors)（只用浅色主题），语义变量在 `src/styles/tokens.css`，场景颜色在 `src/scene/palette.ts`。
- 嵌套圆角按"外圆角 − 内边距 = 内圆角"计算，变量也在 `tokens.css`。

## 数值

`npm run report` 让三种机器人玩家在三个难度下用真实的逻辑核心打完整局，生成 [docs/balance.md](docs/balance.md) 和曲线图。改完数值重跑一次，确认单局时长和胜负还在目标区间。

## 排行榜（Supabase）

1. 在 Supabase 新建项目，或者用已有项目。
2. **Authentication → Sign In / Providers**，打开 **Allow anonymous sign-ins**。玩家不用注册，每个浏览器自动获得一个匿名身份。
3. 建表和函数，二选一：
   - 用 CLI：`supabase link --project-ref <项目 ref>`，然后 `supabase db push`
   - 或者把 `supabase/migrations/` 下的两个 SQL 文件按文件名顺序粘到 SQL Editor 执行
4. 在 **Project Settings → API** 复制 Project URL 和 anon key（或 publishable key），填到下面 Render 的环境变量里。本地开发时填到 `.env.local`，格式参考 `.env.example`。

现在有两个榜：最高领地（曾经占到的最大比例）和各难度最快胜利，数据在 `territory_scores` 表。旧版本的伤害榜（`scores` 表）原样保留、不再使用。表不对客户端开放，只能通过几个 `security definer` 函数读写。服务端会做轻量校验：可信的游戏时长不能比真实时间涨得快，领地比例要和游戏时长匹配，胜利至少要 15 分钟，每人每 15 秒最多更新一次。存档在本地，所以这些校验只能拦住明显改过数值的情况，防不住所有作弊。

## 部署（Render）

1. Render → **New → Blueprint**，选这个仓库，会读取 `render.yaml` 建一个静态站点。
2. 填 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY`。
3. 部署。Vite 在构建时写入这两个变量，修改后要重新部署才会生效。

模型文件通过 Render 的 CDN 分发，带缓存头。

## 素材

3D 模型来自 [Polyfork](https://polyfork.dev)，按 CC BY 4.0 授权使用，完整署名见 [CREDITS.md](CREDITS.md)，游戏内的"设置 → 制作人员"也能看到。

免费素材里没有猛犸、剑齿虎、犀牛、老虎、野猪、蚊子这些，所以在 Polyfork 的动画模型上做了改装（`src/scene/kitbash.ts`）：用 Radix 配色重新上色，再把程序生成的象牙、獠牙、角、口器挂到头部骨骼上，跟着动画动。蜜蜂由胡蜂改色，出租车由轿车改色。人物模型没有自带动画，走路动作由 `src/scene/humanRig.ts` 驱动；不同职业的人用颜色区分。

- 草帐篷、萨满帐篷、蜂巢、花海、蝙蝠洞、稻草人、大石坝、捕虫灯、狼嚎岩、荆棘丛、毒沼、藤墙、集结旗、蝴蝶和蝙蝠由 `src/scene/procedural.ts` 用代码生成。
- `npm run assets`：按 `scripts/assets.manifest.json` 下载模型并用 meshopt 压缩，同时重新生成署名文件。
- 老窝、火山、人类前哨站和地图上的小道具是项目自制的，由 `tools/blender/models.py` 用 Blender 的 Python 模块生成，风格对齐 Polyfork：单一材质、顶点色、平直着色。重新生成需要先安装 Blender：`pip install bpy==5.2.3`（Python 3.13），然后运行 `npm run models`。如果 bpy 装在别的 Python 里，用 `BLENDER_PYTHON=/path/to/python npm run models`。
- 开发服务器上打开 `/lab.html?set=world`：自制模型的陈列页；`/lab.html`：生物模型陈列页（不会打进生产包）。
- 生物和建筑图标由 three.js 在运行时从模型渲染；音效用 Web Audio 合成，没有音频文件。
