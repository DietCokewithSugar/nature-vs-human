# 人类账单支付

自然联合起来，从人类手里把地收回来。面向电脑的挂机构筑版星际争霸 / 魔兽争霸 3 / 红色警戒：你在自己的地上盖窝，窝自动出兵，兵自己探索、抢地、往人类主城推进。你决定的是**养什么、养多少、盖在哪、旗子插在哪**，打仗不用你操作。

- **大地图 + 战争迷雾**：80 × 80 格的地图，每局随机生成，结构像星际的天梯图一样固定。没去过的地方是黑的，去过的地方蒙一层暗色、人类建筑按上次看到的样子显示，兵走到哪看到哪。
- **按时代开圈**：冰河时代只开放中间 32 × 32 格，每过一关进入下一个时代，地图向外开一圈（古代、工业、现代），新的一圈里有人类城镇、自然飞地、湖、火山和资源点。
- **开局**：人类主城在正中，占冰河时代土地的 51–53%；自然只有母树和几块零散的小飞地；其余是中立的茂密森林和沙丘。双方家门口都有森林、湖、沙丘和火山，湖海和火山谁也占不了。
- **一格一格抢地**：每块地有 −100（人类）到 +100（自然）的控制值，越过 ±50 换主人；有建筑的地块要先把建筑拆掉才能翻。
- **地面跟着变**：自然的地是野花草地、杂草沙地、彩色石子海滩、冰川、芦苇淤泥溪流；人类的地按时代从平整土地，到稻田、石板路、规整溪流，到砖地、瓷砖地，再到柏油路、草坪、花坛、白沙滩。
- **食物链**就是人口上限：草场产草，食草动物（蚂蚁、大角鹿、猛犸）吃草、产肉，食肉动物（狼、剑齿虎、洞熊）吃肉。
- **推关**：拆掉人类主城就过关，三选一拿一张强化，进入下一个时代。母树倒下这一轮就结束，带着基因买永久天赋，再来一轮。

这一版的兵种和建筑还是冰河时代的（自然 6 种动物、人类 4 种人），古代以后的时代先换地图和地面。规则详见 [docs/design.md](docs/design.md)，数值验证见 [docs/balance.md](docs/balance.md)，美术规范见 [docs/art-style.md](docs/art-style.md)。暂时没有离线收益：页面开着才算时间。

## 一关怎么打

| 项目 | 规则 |
|---|---|
| 胜利 | 拆掉地图正中的人类主城，进入下一个时代，地图向外开一圈 |
| 失败 | 母树被拆，这一轮结束 |
| 盖建筑 | 先选建筑（或按 1–8），再点自己领地上发光的空地；或者先点空地再选建筑；或者点「自动选位」。建筑之间至少隔一格 |
| 兵怎么走 | 自己探索：沿前线抢还不是自己的地、往没去过的地方走、慢慢往人类主城压；有人类打到自己的建筑，附近的兵回来救 |
| 集结旗 | 右键地图插旗（最多 3 面），兵往最近的旗子打、抢旗子周围的地；点旗子拔掉 |
| 领地 | 兵站在哪块地上就把它往自己这边推，越过一半换主人；有对方建筑的地翻不过来。占着的地和资源点每秒给生机 |
| 升级 | 升级在物种上（像魔兽争霸铁匠铺里的攻防）：狼升一级，所有狼都变强，建筑被拆了也不掉 |
| 拆除 | 自己的建筑可以拆掉，退一半的钱 |
| 人类 | 电脑控制、不受迷雾影响：看你场上什么多就盖克制它的营地，哪里被压得紧就在哪盖瞭望塔；士兵攒够一波一起出击。每 70 秒改良一次工具，全体变强 |

## 食物链

| 资源 | 从哪来 | 用来做什么 |
|---|---|---|
| 生机（钱） | 母树、占着的地、资源点、杀人和拆房 | 盖建筑、升级 |
| 草（每秒产量） | 草场 | 养食草动物 |
| 肉（每秒产量） | 活着的食草动物 | 养食肉动物 |

窝要出兵时，如果再多一张嘴就吃不饱，就先不出，窝上会冒出缺的东西（草或肉）。产量突然掉下来（草场被拆、鹿被杀光），存粮先顶着，存粮吃完那一层就开始挨饿掉血。人类也一样：晾肉架产食物，拆了它人类就出不了那么多兵。

## 兵种和建筑（冰河时代）

数值以 `src/core/config/` 为准。

| 一方 | 单位 | 从哪出 | 吃 | 定位 |
|---|---|---|---|---|
| 自然 | 蚂蚁 | 蚁丘 | 草 0.3/秒，产肉 0.08 | 群体，出得快，拆建筑 ×2 |
| 自然 | 大角鹿 | 鹿林 | 草 1/秒，产肉 0.5 | 前排；每次接敌第一下冲锋 ×3 |
| 自然 | 猛犸 | 猛犸冰谷 | 草 3/秒，产肉 1.2 | 重坦，拆建筑 ×2，踩踏打一片 |
| 自然 | 狼 | 狼穴 | 肉 0.6/秒 | 快；身边每多一只狼 +10%（最多 +50%）；咬投矛手 ×1.5 |
| 自然 | 剑齿虎 | 剑齿虎岩洞 | 肉 1/秒 | 刺客；对半血以下的目标 ×2 |
| 自然 | 洞熊 | 熊洞 | 肉 1.4/秒 | 肉盾；远程伤害对它 −40% |
| 人类 | 采集者 | 人类主城 | 食物 | 去前线推地、捡物资 |
| 人类 | 长矛手 | 长矛营地 | 食物 | 近战，打猛兽 ×1.75 |
| 人类 | 投矛手 | 投矛营地 | 食物 | 远程，打大型动物 ×1.5 |
| 人类 | 火把手 | 火塘 | 食物 | 范围火焰，打蚂蚁 ×2.5 |

另外：自然有**草场**（产草）和**古树**（防御，扔松果）；人类有**晾肉架**（产食物）和**瞭望塔**（防御，扔矛）。母树和人类主城自己也会打靠近的敌人。

## 三选一和天赋

- 每关打赢后三选一，这一轮一直有效、可以叠加：物种强化（兵蚁、狼群战术、厚毛……）、食物链（丰美草场、繁茂鹿群、顶级掠食者……）、全局（迁徙、繁殖季、深根……）。抽卡偏向你正在养的物种。
- 母树倒下，或者自己点「回归大地」，按通关数结算基因。基因买永久天赋：开局生机、母树血量、全体攻击、全体血量、产草、三选一换一批的次数。

## 本地运行

需要 Node 22.12 或更高版本；重新画像素图还需要 Python 3 和 Pillow（`pip install pillow`）。

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # 逻辑核心 + 排行榜 SQL 测试
npm run sim          # 四种机器人各玩一阵，看打到第几关
npm run report       # 多个种子跑完，重新生成 docs/balance.md
npm run sprites      # 用 art/ 里的代码重画所有像素图和地块（public/sprites/）
npm run frames       # 重新生成界面的像素边框和图标（src/styles/frames.css）
npm run font         # 改了文案以后，重新裁剪像素字体（public/fonts/pixel-ui.woff2）
npm run build        # 类型检查 + 打包到 dist/
```

没有配置 Supabase 也能玩，排行榜会显示离线。开发服务器上可以在控制台用 `__game` 直接改状态（比如 `__game.run.essence = 9999`，或者 `__game.run.explored.fill(1)` 揭开迷雾）。

## 架构

按增量游戏通用分层组织，逻辑核心不依赖引擎和平台：

| 层 | 目录 | 内容 |
|---|---|---|
| 外壳 | `src/shell/` | 启动、20 Hz 循环、自动存档 |
| 表现层 | `src/pixel/`、`src/ui/`、`src/styles/` | 地图（PixiJS）和像素风的 Preact 界面，只读状态、发指令。`pixel/ground.ts` 把地块按 8 × 8 格烘焙成块（谁占着变了才重画），`pixel/fog.ts` 是战争迷雾，`pixel/scene.ts` 是镜头、资源点、建筑、单位、弹道、特效和集结旗；`ui/hud.tsx` 是顶栏、侧栏和食物链；`ui/minimap.tsx` 是小地图；`ui/modals.tsx` 是三选一、一轮结束和设置 |
| 逻辑核心 | `src/core/` | 纯 TypeScript，可以在 Node 里直接跑。`map/grid.ts` 是格子和时代圈，`map/generate.ts` 按种子生成地图，`map/nav.ts` 是寻路（距离场）；`sim/` 是模拟：经济和食物链、出兵、战斗和走位（`march.ts` 决定兵往哪走）、领地、迷雾（`vision.ts`）、人类 AI |
| 数据 | `src/core/config/`、`src/data/`、`supabase/` | 配置表、本地存档、排行榜 |
| 美术 | `art/` | 用代码画的所有像素图和地块（Python + Pillow），`npm run sprites` 生成 `public/sprites/` |

几个约定：

- 所有数值在 `src/core/config/`：`units.ts`（血量、攻击、食量、克制）、`buildings.ts`（价格、出兵、产出）、`balance.ts`（经济、领地、人类成长）、`picks.ts`（三选一）、`talents.ts`（天赋）。调数值不用改公式。
- 模拟用固定步长（0.1 秒）和带种子的随机数，同一个种子、同样的操作打出来的局一模一样，测试和平衡报告都靠这一点。地图也由种子生成，存档里只存种子。
- 所有界面文案在 `src/ui/copy.ts`。
- 每个像素都来自 Resurrect 64 调色板，`npm run sprites` 会检查。

## 排行榜（Supabase）

1. 在 Supabase 新建项目，或者用已有项目。
2. **Authentication → Sign In / Providers**，打开 **Allow anonymous sign-ins**。
3. 建表和函数：`supabase link --project-ref <项目 ref>` 然后 `supabase db push`；或者把 `supabase/migrations/` 下的 SQL 文件按文件名顺序粘到 SQL Editor 执行。
4. 在 **Project Settings → API** 复制 Project URL 和 anon key，填到 Render 的环境变量里；本地开发填到 `.env.local`（参考 `.env.example`）。

现在的榜是「最高通关」，数据在 `stage_scores` 表（`20261109000000_stage_board.sql`）。旧版本的伤害榜和领地榜原样保留、不再使用。表不对客户端开放，只能通过 `security definer` 函数读写；服务端做轻量校验：可信的游戏时长不能比真实时间涨得快，每关至少 40 秒，每人每 15 秒最多更新一次。

## 部署（Render）

1. Render → **New → Blueprint**，选这个仓库，会读取 `render.yaml` 建一个静态站点。
2. 填 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY`。
3. 部署。Vite 在构建时写入这两个变量，修改后要重新部署才会生效。
