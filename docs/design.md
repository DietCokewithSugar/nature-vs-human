# 设计文档 v5：大地图、战争迷雾、按时代开圈

> 面向电脑，玩法是挂机构筑版的星际争霸 / 魔兽争霸 3 / 红色警戒：你盖建筑、搭配兵种，打仗和走位全自动。
> 数值以 `src/core/config/` 为准，这里只写规则和意图。平衡结果见 [balance.md](balance.md)。

## 一句话

人类占着地图中间的一大片，自然只有母树和几块零散的小飞地。你在自己的地上盖窝，窝自动出兵，兵自己探索、抢地、往人类主城推进。拆掉主城就进入下一个时代：地图向外开一圈，人类的地面换成新时代的样子。

参考：星际争霸的天梯地图（固定骨架、对称的资源、隘口）和战争迷雾，魔兽争霸 3 的自定义地图 Castle Fight（盖建筑自动出兵），Northgard（按地块扩张、慢慢探索），云顶之弈（搭配和克制）。

## 地图

一张 80 × 80 格的方形地图，一格（地块）32 × 32 像素。每局按种子生成：大的结构固定，细节随机。

```
 ┌──────────────────────────────────────┐  现代：最外一圈，东边和南边是海
 │  ┌──────────────────────────────┐    │  工业
 │  │  ┌──────────────────────┐    │    │  古代
 │  │  │  ┌──────────────┐    │    │    │  冰河时代：中间 32 × 32 格
 │  │  │  │ 自   人 人 人 │    │    │    │
 │  │  │  │ 林  [主城] 湖 │    │    │    │  人类城镇、自然飞地、湖、
 │  │  │  │ 母树  火山 自 │    │    │    │  火山、森林、沙丘散在每一圈
 │  │  │  └──────────────┘    │    │    │
 │  │  └──────────────────────┘    │    │
 │  └──────────────────────────────┘    │
 └──────────────────────────────────────┘
```

- **地形**：草地、森林、沙丘、海滩、雪原、溪流（浅水）、湖海（深水）、火山。湖海和火山谁也占不了、也走不过去；其余都能走、能占。森林里不归你的地会让你走得慢一些。
- **按时代开圈**：冰河时代只开放中间 32 × 32 格。每进入下一个时代，向外开一圈 8 格宽的地：古代 48 × 48，工业 64 × 64，现代 80 × 80。没开放的地方是黑的，边上有一圈金色虚线。
- **开局**：人类主城在正中，人类占冰河时代可占土地的 51–53%（从主城往外长，先占开阔地）。自然只有母树所在的小飞地（西南角）和另外三个角上的小飞地。其余是中立的茂密森林和沙丘，中间偏冷的地方有雪原。
- **双方家门口都有**森林、湖、沙丘和火山，各带一个**资源点**（林中蘑菇圈、泉眼、琥珀坑、地热口）。占着资源点的一方每秒多拿收入。
- **外圈**：每一圈有 3–4 个人类城镇（带晾肉架、营地、瞭望塔）、3 个自然飞地、湖、火山和更多资源点。外圈的归属不受 51–53% 的限制，城镇以外大多是中立地。
- 地图像星际的天梯图一样，结构是固定的：主城、母树、家门口的四种地形、每圈的城镇和飞地都在差不多的位置；具体形状、森林还是沙丘、飞地落在哪，由种子决定。

## 领地

- 每块地有控制值，−100（人类）到 +100（自然），越过 ±50 换主人，中间是中立。
- 兵站在哪块地上，就把那块地往自己这边推，速度由兵种的「侵占」决定（蚂蚁、猛犸、采集者推得快）。两边的兵都站在同一块地上时，谁也推不动。
- **有建筑的地块翻不过来**：对方最多把它推到中立（±49），要先把建筑拆掉。建筑自己也会慢慢把脚下的地拉回来。
- 自然在自己的地上盖建筑；人类电脑也只在自己的地上盖。建筑之间至少隔一格，资源点上不能盖。
- 占着的每块地、每个资源点每秒给收入。

## 战争迷雾

和星际争霸一样分三层：

| 状态 | 看到什么 |
|---|---|
| 没去过 | 全黑 |
| 去过、现在没人看着 | 盖一层暗色：看得到地形和谁占着，人类的建筑按上次看到的样子显示成灰色，看不到人类的兵 |
| 看得见 | 全部 |

- 自然的兵和建筑周围看得见（各兵种视野不同，狼最远，古树和母树更远）；自己占着的地和它周围一格也一直看得见。所以开局能看到母树和几块零散的飞地，其他地方要靠兵一点点去探。
- 人类电脑不受迷雾影响。

## 兵怎么走

不用控兵。兵没有可打的目标时：

1. **有人类打到自己的建筑**（建筑 4 格以内有人类）：附近 16 格内的兵都回来救。
2. **插了集结旗**（右键地图，最多 3 面）：去最近的那面旗，到了以后抢旗子周围 4 格的地。
3. **什么都没有**：自己探索。看自己周围的地，挑一块还不是自己的、或者还没探过的地走过去抢；离人类主城越近越优先，看见过的人类建筑更优先，别的兵已经去的地方就换一块。所以兵会沿着前线散开、把迷雾推开，同时慢慢往主城压。

遇到敌人在 2 格多以内就打。寻路绕开湖海和火山。

人类：采集者去抢离自己最近的、还不是人类的地（偏向自然那边）；士兵平时守在家里，或者去自然的兵压进来的地方，攒够一波（6 + 2 × 关卡）才一起去打离得最近的自然建筑，打剩不到 2 个就回来重新攒。每关开头 150 秒内不出击。

## 一关怎么打

- 胜利：拆掉人类主城。失败：母树被拆，这一轮结束。
- 打赢以后三选一，然后进入下一关：**第 n 关是第 min(n, 4) 个时代**，新时代开一圈地图（按地图预设铺好那一圈的归属和城镇）。
- 进入下一关时：场上的兵清空；你的建筑、占下的地、物种等级、生机都留着；人类在原地重建主城（主城周围 2.5 格收回给人类），重建开局建筑和每个已开放圈里还在人类地上的城镇。现代以后地图不再变大，人类继续变强，可以一直推下去。
- 时间站在人类那边：人类每隔一段时间改良一次工具，全体变强。

## 两方的地面

地面随谁占着而变（控制值越过 20、35、50 分三步显出来）：

| 一方 | 地形 → 地面 |
|---|---|
| 自然 | 草地 → 开满野花的草地；森林 → 野花林地和开花的树；沙丘 → 长满杂草的沙地；海滩 → 彩色石子海滩；雪原 → 冰川；溪流 → 长着芦苇的淤泥溪流 |
| 人类·冰河时代 | 平整土地（森林被砍成树桩） |
| 人类·古代 | 稻田（草地、森林）、石板路（沙丘、海滩、雪原）、规整溪流 |
| 人类·工业时代 | 砖地（草地、森林）、瓷砖地（沙丘、海滩、雪原）、水泥渠 |
| 人类·现代 | 草坪（草地）、花坛（森林）、柏油路（沙丘、雪原）、白沙滩（海滩）、水泥渠 |

自然的地面是不规则的一块块，人类的地面是整齐的方格，边上有一道路沿：一眼看出边界在哪。

## 食物链、物种、建筑、三选一、天赋

和 v4 一样（详见 README）：

- 草场产草，食草动物吃草、产肉，食肉动物吃肉；吃的不能超过产的。
- 升级在物种上，所有同种的兵一起变强。
- 克制：火把克蚂蚁，长矛克猛兽，投矛克巨兽；狼咬投矛手，猛犸和蚂蚁拆房子。人类看你出什么就盖克制它的营地。
- 每关三选一；母树倒下或者回归大地就结算基因、买永久天赋。

## 电脑操作

| 操作 | 作用 |
|---|---|
| WASD / 方向键 / 鼠标推屏幕边 / 左键拖拽 | 移动镜头 |
| 滚轮、+ / − | 缩放（整数倍，像素不糊） |
| 左键 | 选建筑、选空地；拿着建筑时在空地上盖 |
| 右键 | 插集结旗；拿着建筑或在插旗模式时取消 |
| 1 – 8 | 选建筑（选中空地时直接盖在那里） |
| F | 插旗模式 |
| 空格 / H | 回到母树 |
| Esc | 取消 |
| 左下角小地图 | 点击或拖动移动镜头 |

## 和 v4 相比

- 三条路的横版地图 → 80 × 80 格的开放地图，按时代开圈，每局随机生成。
- 固定建造位 → 在自己的地上任意空地盖。
- 一段一段的路 → 一格一格的地，控制值 ±100。
- 新增战争迷雾、集结旗、小地图、资源点、人类的进攻波次。
- 时代回来了：每关一个时代（第 4 关以后都是现代），地面跟着时代变。
- 修了一个老问题：人类主城以前因为射击和出兵共用一个计时器，从来不出采集者。
