# 美术规范（像素画面）

这一版所有单位、建筑、地图和图标都是**在代码里逐像素画的**（`art/`，Python + Pillow），没有外部美术素材。风格统一靠这里的规则和 `npm run sprites` 这条管线。

## 一、可读性是第一位

每条规则都为了一眼看懂：

| 问题 | 做法 |
|---|---|
| 不知道哪是我家、哪是敌人 | 自然的地是不规则的一块块（野花、杂草、彩石、冰川、芦苇），人类的地是整齐的方格（平整土地、稻田、砖、柏油），边上一道路沿 |
| 不知道哪里没去过 | 战争迷雾：没去过是全黑，去过但看不见蒙一层暗色，看得见的地方全亮；没开放的时代圈是黑的，边上一圈金色虚线 |
| 分不清谁是谁的 | **阵营色**：自然薄荷绿（`#30e1b9`），人类橙红（`#ea4f36`）。单位脚下一圈阵营色、血条是阵营色；动物戴薄荷绿叶子项圈，人系橙红头带；自然的建筑有发光的符文或眼睛，人类的建筑插橙红旗；资源点下面一圈占着它那一方的颜色 |
| 地形看不出来 | 中立的森林是又密又暗的松林，沙丘有风纹，雪原发白，湖海深蓝，火山是黑岩加岩浆缝和一座冒烟的火山锥 |
| 东西太小、太乱 | 单位和建筑都比地块大；树只长在森林格子里 |

## 二、硬规则

| 规则 | 内容 |
|---|---|
| 调色板 | 只用 [Resurrect 64](https://lospec.com/palette-list/resurrect-64)（`art/kit.py` 的 `R64`）。`npm run sprites` 会逐像素检查，不在调色板里就报错 |
| 像素密度 | 一个地块 32 × 32 像素，地图 80 × 80 格（2560 × 2560）。画面只按整数倍放大（按设备像素算），不旋转、不缩放素材。弹道这类会转方向的东西，画 5 个斜度挑一个 |
| 地块 | `art/map.py` 画一套地块：每种地形 3 个变体（`tile/`），地形交界的毛边（`edge/`，优先级高的地形盖住低的），自然的地面（`own/nature/`，40 × 40、四周多出 4 像素的不规则一块），人类每个时代的地面（`own/human/<时代>/`，32 × 32、可以无缝拼接），人类地面的路沿（`curb/`），树、石头、火山锥（`deco/`），资源点（`site/`）和集结旗（`flag/`）。游戏把它们按格子拼起来，每 8 × 8 格烘焙成一块 |
| 视角 | 单位侧面朝右（朝左时游戏镜像）；建筑正面、略从上往下看 |
| 光源 | 左上方。亮面偏暖、暗面偏冷 |
| 描边 | 1 像素外描边，颜色 `#2e222f`（调色板最深色，不用纯黑）。地面不描边 |
| 锚点 | 脚底 / 地基正中，写在 `atlas.json` 每帧的 `anchor` 里 |

## 三、尺寸

| 类别 | 尺寸（像素） | 例子 |
|---|---|---|
| 小虫 | 约 15 × 10 | 蚂蚁（背着薄荷绿叶子） |
| 人 | 约 9 × 18（带武器更宽） | 采集者、长矛手、投矛手、火把手 |
| 中型兽 | 25–30 宽 | 狼、剑齿虎、洞熊、大角鹿（鹿角高） |
| 大型兽 | 约 45 宽 | 猛犸 |
| 普通建筑 | 30–46 宽 | 窝、营地、晾肉架 |
| 主基地 | 约 70 宽 | 母树、人类主城（占 2 × 2 格） |
| 地块 | 32 × 32 | 每格一块 |
| 树 | 约 18 × 28 | 中立森林每格 3–4 棵 |

人画成 Q 版、比动物小：要一眼看出「一群小人在围猎巨兽」。

## 四、怎么画（工作流）

用的是 [pixel-art-studio](https://github.com/Gamezxz/pixel-art-studio) 的方法和绘制库（MIT，收录在 `art/lib/`）：**先剪影、再大色块、再明暗、最后细节**，每一步都要**看**。

1. 改 `art/units.py` / `art/buildings.py` / `art/props.py` / `art/map.py` 里的代码。单位由部件拼（身体用字母网格画，腿是参数化的关节线），走路和攻击帧是函数调用，不是一帧帧手画。
2. `cd art && python3 preview.py wolf elk`：把这几个单位的所有帧放大 8 倍、铺在雪地色上，存到 `art/.preview/units.png`。
3. **看图挑毛病**，对照下面的检查清单，改代码，再看。每个素材至少改两三轮。
4. `npm run sprites`：画全部、检查调色板、打包成 `public/sprites/atlas.png` + `atlas.json`；`art/.preview/` 里有全部单位、建筑和地块（`ground.png`）的总览图。

动画帧数：走路 4 帧（腿交替、身体起伏 1 像素），攻击 2 帧（蓄力、出手）。火焰 3 帧循环。

## 五、检查清单（新素材合入前）

1. **剪影**：只看轮廓能认出是什么。猛犸要有圆顶头、鼻子、獠牙；剑齿虎的牙要露在下巴外面；狼耳朵竖着、尾巴下垂。
2. **阵营**：有没有阵营色的那一块（项圈、头带、旗、发光）。
3. **对比**：在雪地（`#c7dcd0`）和苔藓（`#547e64`）上都要跳出来。
4. **干净**：没有孤立的杂点；描边完整；同一个素材里像素大小一致。
5. **进游戏看**：桌面 2 倍、手机横屏 1 倍（每个美术像素 3 个设备像素）都要能认出来。

## 六、界面

界面沿用像素 UI 规范：木框羊皮纸面板、浅色纸卡片、有厚度的像素按钮、直角、硬阴影、像素字体（缝合像素字体 12 / 18 / 24 像素）。边框和小图标在 `scripts/ui-frames.mjs` 里用字母画，`npm run frames` 生成 `src/styles/frames.css`；HUD 样式在 `src/styles/game.css`。界面里的单位和建筑小图直接取自像素图集（`src/pixel/atlas.ts` 的 `frameUrl`）。

布局（面向电脑）：地图在左、面板在右，小地图在地图左下角（像星际争霸）；竖屏时地图在上、面板在下，不显示小地图。顶栏放关卡和时代、人类主城的血量、领地比例，面板放生机、食物链、集结旗、建造和进化。
