# 美术规范（像素画面）

这份规范决定以后加的素材和界面能不能和现有的对上。渲染层（`src/pixel/`）只负责把图集里的帧摆到地图上，**风格统一靠的是这里的规则和 `npm run sprites` 这条管线**：不管素材是 3D 模型烘焙的、代码画的、手绘的、AI 生成的还是下载的，最后都过同一道调色板、描边和尺寸检查。

## 一、风格定位

16-bit 俯视 RPG 风格（类似《星露谷物语》、GBA 宝可梦）：俯视 3/4 视角，地面是正方形网格，物体露出正面和顶面。这是开源像素素材最多的一类，以后找素材、找画师、用 AI 生成都最容易对上。

可读性优先于写实：在手机上要一眼分清这是什么、是谁的。

## 二、硬规则

| 规则 | 内容 | 在哪里定义 |
|---|---|---|
| 调色板 | 只用 [Resurrect 64](https://lospec.com/palette-list/resurrect-64) 的 64 种颜色。地面、精灵、特效、图标都一样。外来素材烘焙时自动吸附到最近的颜色（OKLab 距离） | `src/pixel/palette.ts` |
| 像素密度 | 一格 = 16 像素（4 个世界单位）。素材按这个比例画，**不缩放、不旋转**，不同大小的像素不能出现在同一个画面 | `src/pixel/specs.ts` 的 `TILE` |
| 缩放 | 镜头只停在整数倍（每个美术像素 = 整数个屏幕物理像素），捏合缩放松手后吸附 | `src/pixel/scene.ts` 的 `snap()` |
| 视角 | 俯视 3/4。动物和人朝右画（朝左时自动镜像），稍微侧向镜头；建筑正面朝镜头 | 烘焙相机：动物仰角 28°，建筑和树 40° |
| 光源 | 左上方。三档明暗：亮面（顶）、中间（正面）、暗面（右侧），暗面偏冷（偏蓝紫），亮面偏暖 | `src/bake/bake.ts` 的 `shade()` |
| 描边 | 单位、建筑、树、图标都有 1 像素描边，颜色是调色板最深色 `#2e222f`（不用纯黑）。地面不描边 | `outline()` |
| 锚点 | 脚底（建筑是地基）的正中。图集 JSON 里每帧都带 `anchor` | 图集 `atlas.json` |
| 杂点 | 不允许孤立的单个像素（和八个邻居都不同色）：烘焙时自动并进周围颜色 | `cleanup()` |

## 三、尺寸档位

| 类别 | 尺寸（像素） | 例子 |
|---|---|---|
| 小虫 | 9–10 宽 | 蚂蚁、蝗虫、蚊子、蜜蜂、白蚁 |
| 小兽、鸟 | 11–14 宽 | 老鼠、鸽子、乌鸦、家猫、狗 |
| 中型兽 | 15–21 宽 | 狼、野猪、剑齿虎、洞熊、老虎 |
| 大型兽 | 22–30 宽 | 鳄鱼、野牛、犀牛、鲨鱼、猛犸、大象 |
| 人 | 约 15 高（含帽子 17） | 所有职业，同一个 Q 版模板 |
| 车船 | 19–22 宽；飞机 44 | 出租车、渔船、客机 |
| 建筑 | 宽 ≈ 3D 尺寸 × 3.2，高不超过 46 | 帐篷 18 宽，摩天楼 46 高 |
| 树 | 宽 14–20，高 20–26 | |

单位比真实比例大（蚂蚁画得和老鼠差不多），这是故意的：手机上要看得见。具体数字在 `src/pixel/specs.ts` 的 `UNIT_PX`。

## 四、可读性规则

- **明暗分层**：地面低对比、成片的颜色（噪点成团出现，不是撒胡椒）；单位和建筑高对比、有描边，从地面上跳出来。
- **阵营区分**：
  - 自然的地是饱和的绿色、沙色；人类的地是灰色、土色，人工的条纹和网格（稻田、砖、瓷砖、柏油、修剪过的草坪）。
  - 单位脚下的影子带阵营色：自然深绿、人类深红。
  - 血条颜色：自然绿、人类红；白条是寿命。只在受伤或快老死时显示，平时不挡画面。
- **剪影优先**：每种动物只看黑色剪影也要能分出来。分不出来的，先改比例（拉长、加角、加牙），再考虑改颜色。
- **人用 Q 版**：头大（8 像素宽）、一个像素的眼睛、短身体。职业靠衣服颜色、帽子和手里的工具区分。
- **树不挡单位**：树、草、石头画在所有单位和建筑下面。
- **同类图标不重复**：一群动物在睡觉只显示一个「Zz」。

## 五、动画

| 动画 | 帧数 | 说明 |
|---|---|---|
| move | 4 | 走、游、飞的循环。人：迈步、并腿（身体抬 1 像素）、迈步、并腿 |
| rest | 1–2 | 站着或待机 |

只画朝右的一套，朝左时游戏自动镜像（像素策略游戏的常见做法，省一半工作量）。建筑、树没有动画，只有一帧。

## 六、素材从哪来

| 来源 | 怎么进游戏 | 能不能自动对上 |
|---|---|---|
| 3D 模型（Polyfork 等，CC BY） | 在 `specs.ts` 登记，`npm run sprites` 烘焙 | 能：同一个相机、光、调色板、描边 |
| 代码画的人 | `src/bake/people.ts` 加一个职业的衣服、帽子、工具 | 能：同一个身体模板 |
| 手绘 / AI 生成 / 下载的 PNG | 放进 `art/sprites/<key>/move0.png` 等，再烘焙 | 颜色和描边自动对上；明暗画法和细节多少要按上面的规则人工检查 |

外部素材的建议：

- **先挑同一套、同一个作者的**：比如 Kenney 的 16 像素系列（CC0）彼此风格一致，Ninja Adventure（CC0）有日式建筑。
- **LPC 素材**（OpenGameArt）是 CC-BY-SA / GPL：可以用，要署名，改过的美术也要按同样的授权公开。角色是 32 像素以上，要缩小或只参考。
- **itch.io 上的免费包**：很多写着「不能再分发」。仓库是公开的，放进来就算再分发，用之前看清授权。
- **AI 生成**：生成时提示词写明「16-bit pixel art, top-down 3/4 view, facing right, 1px dark outline, limited palette」，尺寸按上面的档位。生成后放进 `art/sprites/` 烘焙一遍，调色板和描边会被统一；再看一眼有没有杂点、光源方向对不对。
- 每加一个外部素材，在 `CREDITS.md` 写上来源和授权。

## 七、界面

界面和地图是同一套像素语言，参照《星露谷物语》和《泰拉瑞亚》：

| 规则 | 内容 | 在哪里定义 |
|---|---|---|
| 像素大小 | 界面的 1 像素 = 2 CSS 像素（`--u`），和手机上地图的像素一样大 | `src/styles/tokens.css` |
| 颜色 | 只用 Resurrect 64。旧代码里的 Radix 颜色名（`--grass-9` 这类）在 `palette.css` 里改指到调色板，按色相成组，保留「1–2 背景、3–5 组件、6–8 边框、9–10 实色、11–12 文字」的分工 | `src/styles/palette.css` |
| 面板 | 木框（墨色外框、亮木、木、暗木、深色内沿，共 5 像素，切角）+ 深羊皮纸底 `#fbb954` | `--frame-wood` |
| 卡片 / 格子 | 面板里的卡片是浅色纸 `#fdcbb0`，棕色细框，左上方一道阴影（凹进去的感觉） | `--frame-slot` |
| 按钮 | 墨色外框、顶部一行亮色、底部两行暗色当厚度；按下时厚度变一行、整体下沉 1 像素。颜色按意思选：绿 = 可以做、红 = 危险 / 关闭、金 = 升级 / 进行中、纸色 = 普通、木色 = 没选中的标签页、灰 = 不可用 | `--btn-*` |
| 进度条 | 墨色外框、内部顶上一行暗影；填充是平涂色加顶部一行高光 | `--frame-track` |
| 角 | 不用圆角。边框在角上切掉一个像素 | 所有 `--frame-*` |
| 阴影 | 只用硬阴影（不模糊），偏移是整像素 | `tokens.css` 的 `--drop` |
| 字体 | 缝合像素字体 12px（SIL OFL 1.1），只用 12 / 18 / 24 / 36 像素四档，不加粗、不描边。地图上的文字（数字飘字、昼夜时间）用 8 方向 2 像素硬描边 | `tokens.css`、`pixel.css` |
| 图标 | 像素画，和边框一起画在 `scripts/ui-frames.mjs` 里（自然之元、人类的钱、基因点、关闭、太阳、月亮……） | `--icon-*` |
| 动效 | 弹窗、提示用一格一格的步进动画（`steps()`），不用平滑曲线和模糊 | `pixel.css` |

加新界面时：

1. 能用现成的框就用现成的：面板 `--frame-wood`、卡片 `--frame-slot`、小图和徽章 `--frame-ink`、按钮 `--btn-<颜色>`。
2. 要新的边框或图标，在 `scripts/ui-frames.mjs` 里用字母画，跑 `npm run frames`。
3. 新文案里有新的字，跑一次 `npm run font`（不跑也能显示，只是会多下载完整字体）。
4. 在手机竖屏上看一眼：顶部状态栏不要变高，底部面板收起时只剩三个标签页。

## 八、检查清单（新素材合入前）

1. 跑 `npm run sprites`，没有 FAILED。
2. 开发服务器打开 `/bake.html?only=<key>`，放大看：颜色都来自调色板、描边完整、没有杂点。
3. 进游戏在手机尺寸下看（默认缩放，一屏约 13 格）：能不能一眼认出是什么、是哪一方的。
4. 白天和夜里各看一次（夜里整体变蓝，暗色单位容易看不见）。
